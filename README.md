# SabakanOS

Linux ベースのオペレーティングシステム「SabakanOS」のプロジェクトリポジトリです。

## 概要

SabakanOS は、軽量かつ拡張性の高い Linux ベース OS の開発を目的としたプロジェクトです。
カーネル、ブートローダー、ルートファイルシステム、ビルドスクリプトなどを統合管理します。

## ビルド手順（簡易版）

1. 依存ツールをインストールする（ビルド必須パッケージなど）。
2. ルートディレクトリで `make` を実行し、ビルドを開始する。
3. 成果物は `build/` ディレクトリに出力される。
4. ISO イメージが必要な場合は、`make iso` を実行する（`iso/` に出力）。

> 詳細なビルド手順は `docs/` または各レーン（A〜E）のドキュメントを参照してください。

## ディレクトリ構成（計画）

- `boot/` — ブートローダー関連
- `config/` — ビルド設定・カーネル設定
- `scripts/` — ビルド・パッケージングスクリプト
- `Makefile` — ビルドのエントリポイント
- `build/` — ビルド成果物（Git 管理外）
- `rootfs/` — ルートファイルシステム（Git 管理外）
- `iso/` — ISO イメージ成果物（Git 管理外）

> `Makefile`、`scripts/`、`config/`、`boot/` は他レーン（A〜E）が所有するため、本レーンでは触りません。
